#  Generate Random Password-

I created my Generate Random Password on my phone. If you know, you know. It was very frusterating, but I managed to pull through. It's very basic, so I will be adding some feautures to it to make it more elaborate. But as it is now, it has a generatePassword function that loops the length of the password and uses a generateRandomNumber funciton to select a random character from String.fromCharCode. There is also a button that allows the user to copy the password to their clipboard.
